# Script Wrappers

These are thin wrappers around the service layer. Prefer the CLI in `dvolley/cli/main.py` for most tasks, but these remain available for manual runs.

## Load rally data

```powershell
.\.venv\Scripts\python scripts/load_data.py
```

## Load full (touch-level) data

```powershell
.\.venv\Scripts\python scripts/load_full_data.py
```
